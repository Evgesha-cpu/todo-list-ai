# Список задач

Тестовое задание для вакансии AI-разработчика. Приложение на HTML, CSS и JavaScript без фреймворков, сборки и сервера приложения.

[Открыть приложение](https://evgesha-cpu.github.io/todo-list-ai/)

- Добавляйте задачи кнопкой или клавишей Enter.
- Отмечайте выполненные задачи, возвращайте их в активные и удаляйте.
- Фильтруйте список и отслеживайте долю выполненных задач.
- Задачи сохраняются в `localStorage` этого браузера. Ошибки чтения и записи отображаются рядом со списком. При повреждении сохранённых данных приложение работает в памяти и сохраняет исходную запись без изменений.

## Запуск

Из корня проекта запустите локальный HTTP-сервер, например через Python 3:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory public
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для размещения достаточно раздать содержимое `public/` по HTTPS с поддержкой JavaScript-модулей (`.mjs`). API, база данных и переменные окружения не нужны.

## Проверки

Автоматические тесты модели задач и хранилища запускаются на Node.js 18+ без установки пакетов:

```sh
node tests/tasks.test.mjs
```

Для ручной проверки добавьте две задачи, отметьте одну, переключите фильтры и обновите страницу. Снимите отметку, удалите задачу и снова обновите страницу. Убедитесь, что пустой ввод вызывает подсказку, а длинный текст задачи переносится на узком экране.

Браузерная проверка в Chromium выполнена на ширинах 320, 375, 768 и 1440 px. Проверены добавление кнопкой и клавишей Enter, переключение статуса, фильтры, удаление, сохранение изменений при перезагрузке и перенос длинного текста. Автоматические тесты также покрывают ошибки чтения и записи хранилища и повреждённые записи.

## Использование AI

OpenAI Codex использовался для проектирования интерфейса, написания кода, подготовки тестов и проверки сценариев. В самом приложении AI-моделей и вызовов AI API нет.
